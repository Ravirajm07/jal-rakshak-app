# Support

JalRakshak is an open-source prototype. It is not an official emergency response, medical, water-safety, flood-warning, or government service.

For general questions, use GitHub Discussions if enabled, or open a GitHub issue with a clear reproduction and environment details.

For security issues, do not open a public issue. Follow `SECURITY.md`.

For emergencies or public-safety decisions, contact the appropriate local emergency services and official authorities.
