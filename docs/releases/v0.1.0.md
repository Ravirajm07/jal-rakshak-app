# JalRakshak v0.1.0 Release Notes

Date prepared: 2026-07-13

## Summary

`v0.1.0` is the first public open-source readiness release for JalRakshak. It documents the actual prototype architecture, removes tracked credential exposure, adds license and community-health files, introduces tests and CI, and records security limitations that must be resolved before production use.

## Highlights

- Added Apache-2.0 license.
- Rewrote README with verified setup, architecture, and safety limitations.
- Removed plaintext demo passwords and a tracked Gemini-key helper script.
- Moved Firebase web config to environment variables.
- Added MongoDB/Firebase architecture documentation.
- Added complaint validation tests and GitHub Actions CI.
- Added SECURITY.md, CONTRIBUTING.md, issue templates, and release documentation.

## Upgrade Notes

- Create `.env.local` from `.env.example`.
- Set Firebase Auth web config values with `NEXT_PUBLIC_FIREBASE_*`.
- Set `MONGODB_URI` for persistent complaint storage, or expect demo fallback behavior in local prototype mode.
- Do not use committed demo credentials from earlier history; rotate or delete any accounts that reused those passwords.

## Release Blockers Before Production

- Add server-side Firebase ID-token verification and admin role checks to complaint APIs.
- Add abuse prevention and rate limiting to write routes.
- Decide and implement the Android/Capacitor packaging strategy.
- Review remaining dependency audit advisories.
- Complete maintainer-led secret revocation and optional Git history cleanup.
