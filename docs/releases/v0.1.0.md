# JalRakshak v0.1.0 Release Notes

Date prepared: 2026-07-13

## Project Summary

JalRakshak v0.1.0 is the first public open-source readiness release for a prototype civic-tech app covering water-quality views, flood-risk indicators, sanitation reports, citizen alerts, and administrative complaint workflows.

This release prepares the repository for public collaboration. It is not a production emergency, medical, public-health, or government system.

## Verified Citizen Features

- Firebase Authentication sign-up and sign-in from the Next.js client.
- Citizen dashboard with simulated water-quality and flood-risk values.
- Report form for issue type, location, description, and optional local evidence selection.
- Report status lookup against the local complaint state.
- Simulated assistant responses for water, flood, alert, and reporting prompts.
- Session disclaimer describing prototype safety limitations.

## Verified Administrator Features

- Admin dashboard view selected by client-side role state.
- Complaint management UI with status updates and admin notes.
- CSV export for complaint data.
- Simulated analytics, alert list, decision-support panel, map markers, and camera grid.
- Optional user-entered IP camera URL display in the browser.

## Mobile Support Status

The repository includes a Capacitor Android scaffold under `android/`. The mobile packaging path is experimental because the current Next.js app uses route handlers for complaint APIs and does not produce a static `out/` directory during the standard build.

## Simulated-Data Disclaimer

Sensor, flood, CCTV, alert, analytics, and assistant information may be simulated. Do not use JalRakshak as the sole source for emergency, medical, public-health, flood-response, or drinking-water decisions.

## Security Improvements

- Removed plaintext demo passwords from tracked documentation.
- Removed current tracked Gemini helper/model artifacts and Firebase debug log.
- Moved Firebase web config to `NEXT_PUBLIC_FIREBASE_*` environment variables.
- Added `.gitignore` coverage for env files, Firebase logs, keys, and service-account JSON.
- Added SECURITY.md and maintainer remediation guidance.
- Added validation and mass-assignment rejection for complaint create/update inputs.
- Added deny-by-default Firestore rules because Firestore is not used by runtime code.

## Testing and CI Additions

- Added Vitest, Testing Library, jest-dom, jsdom, user-event, and v8 coverage tooling.
- Added tests for complaint validation, flood/water safety classification, and CSV export formatting.
- Added `npm run lint`, `npm run typecheck`, `npm run test`, `npm run test:coverage`, `npm run build`, and `npm run check` workflows.
- Added GitHub Actions CI, CodeQL, dependency review, and Dependabot configuration.

## Installation Summary

```bash
git clone https://github.com/Ravirajm07/jal-rakshak-app.git
cd jal-rakshak-app
npm ci
cp .env.example .env.local
npm run dev
```

Node.js 20.9.0 or newer is required by the installed Next.js version. CI uses Node.js 22.

## Upgrade Notes

- Create `.env.local` from `.env.example`.
- Set Firebase Auth web config values with `NEXT_PUBLIC_FIREBASE_*`.
- Set `MONGODB_URI` for persistent complaint storage, or expect demo fallback behavior in local prototype mode.
- Do not reuse previously documented demo credentials; rotate or delete any real accounts that used them.

## Known Limitations

- Complaint API routes do not yet verify Firebase ID tokens server-side.
- Administrator authorization is not enforced at the server/database boundary.
- No production rate limiting or abuse prevention is implemented.
- Firestore is not used by runtime code.
- Android/Capacitor release packaging is not complete.
- Live Gemini integration is not enabled.
- Remaining `npm audit` output reports two moderate advisories tied to Next.js' nested PostCSS dependency metadata.
